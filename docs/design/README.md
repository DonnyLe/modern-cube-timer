# Session manager references

`session-manager.png` is the original approved concept. Later decisions removed its footer actions and added search, filters, selection, bulk deletion, and per-session deletion menus.

`session-manager-local.png`, `session-manager-custom-theme.png`, and `session-manager-mobile.png` are screenshots of the local production build with synthetic session data. The custom-theme capture uses the largest supported workspace corner radii, border thickness, and font scale; this screen keeps its fixed geometry while inheriting the theme colors.
